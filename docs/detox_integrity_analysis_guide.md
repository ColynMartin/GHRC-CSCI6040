# Analyzing whether detox methods preserve integrity

This complements [`integrity_evaluation_plan.md`](integrity_evaluation_plan.md) with a **fixed workflow** for your report: quantitative comparison to baseline plus **qualitative** excerpts.

---

## 1. What “detox methods” means here

In [`configs/detox_conditions.yaml`](../configs/detox_conditions.yaml), list the personality conditions your team treats as **detox-oriented** (e.g. traits you expect to lower toxicity). The script compares each of those to **`baseline`** on the **same** HH `prompt_id`s.

You can separate “expected helpful” vs “expected harsh” traits in the write-up even if both appear in the YAML for one run.

---

## 2. Quantitative analysis

Run (after `hh_*_integrity.csv` and `hh_*_detoxify.csv` exist for baseline and each listed method):

```text
python src/analyze_detox_integrity.py
```

**Outputs**

| File | Content |
|------|--------|
| `outputs/detox_integrity_analysis.csv` | Per-method aggregates: mean Δ Jaccard, mean Δ toxicity, % prompts with toxicity down, % with “integrity preserved” (within tolerance), % **tradeoff** (toxicity down but Jaccard drops more than tolerance), % **win–win** (toxicity down and Jaccard within tolerance). |
| `outputs/detox_integrity_analysis.md` | Same table in Markdown for slides or paper. |

**Interpretation**

- **Token Jaccard** vs `reference_reply` is a **rough** helpfulness proxy (see integrity plan). Low absolute values are common with small/weak LMs; **deltas vs baseline** on the *same* prompts matter most.
- **Detoxify** scores on HH are often small; tune `toxicity_improvement_min` in the YAML so “toxicity_down” is not empty or trivial.
- **Tradeoff %** supports the hypothesis that detox-style prompting can **reduce measured toxicity** while **hurting alignment** with the human-preferred reply.
- **Win–win %** supports the opposite (limited tradeoff for that sample).

---

## 3. Qualitative examples

`outputs/qualitative_examples.md` is generated by the same command. It pulls short **side-by-side** excerpts:

1. **Win–win** — toxicity down, Jaccard within tolerance vs baseline.  
2. **Tradeoff** — toxicity down, Jaccard drops beyond tolerance.  
3. **Integrity loss without clear toxicity gain** — Jaccard drops but toxicity did not improve by your threshold.

For your paper, add **1–2 sentences** under each excerpt explaining *why* the behavior matches (or contradicts) your hypothesis (e.g. more refusal, vaguer answer, off-topic drift).

---

## 4. Suggested report wording

- State **which** conditions you label as detox methods and **why** (HEXACO mapping).  
- Report **aggregate** rows from `detox_integrity_analysis.csv` and **one figure** (e.g. scatter or bar: mean Δ tox vs mean Δ Jaccard per method).  
- Ground claims with **2–3** qualitative blocks from `qualitative_examples.md`, not only averages.

---

## 5. If outputs are missing

Regenerate HH outputs for all conditions you listed, then Detoxify + integrity, then re-run the analyzer:

```text
python src/run_hh_tradeoff_pipeline.py --generate
python src/analyze_detox_integrity.py
```

(Or run generation + `score_detoxify.py hh_` + `run_integrity_all_hh.py` manually if you prefer.)
